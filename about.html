Security

RavenShield runs entirely client-side. Cryptography uses the browser's Web Crypto API (crypto.subtle for SHA hashing, crypto.getRandomValues for all randomness). There's no server to breach and no database of user data to leak.

Responsible disclosure

Found a vulnerability, such as an XSS in a tool or a detection bypass? Please report it privately through the contact below, with steps to reproduce. Bypasses of the injection engine are especially welcome. Each one becomes a new rule.

Privacy

  • What we collect: nothing. There are no analytics scripts or tracking cookies.
  • What your browser stores: your decoys, traps, settings and evidence log, in localStorage for this site.
  • Third parties: none for fonts or scripts; everything is served from this site. The optional breach check calls the Have I Been Pwned range API with a 5-character hash prefix. Heartbeat checks call only the URLs you add.
  • Deleting your data: clear the evidence log in the console, or clear site data in your browser settings.
