Use it in your own app

The engine is one dependency-free file. Drop it in front of any LLM call:

<script src="https://YOUR-SITE/assets/js/lib/shield-engine.js"></script>
<script>
  const r = RavenShieldEngine.inspect(userText);
  if (r.verdict === "block") throw new Error("Injection blocked");
  callModel(r.sanitized);
</script>
