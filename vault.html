RavenVault

Unlimited decoys

Mint decoy identities that nobody legitimate will ever use: tripwire email aliases, realistic passwords, fake cloud keys and tokens. Plant them in repos, drives, wikis and paste sites, then let the Leak Matcher pin any sighting to the exact decoy.

Mint a decoy identity

We build you+rs-xxxx@gmail.com. Mail to it still lands in your inbox, so any message proves the decoy leaked. Gmail, Outlook, Proton, iCloud and Fastmail support this. Stored only in this browser.

Leak Matcher

checks all decoys

Paste anything you found: a paste-site dump, server logs, email headers, an AI model's answer, a breach file. Every decoy token is searched for, including the tripwire alias and the hidden marker.

Watched decoys

Set an inbox rule: filter messages sent to +rs- into a label like RAVEN ALERT with notifications on. Then hit Report trip on the matching decoy to seal it as evidence.
